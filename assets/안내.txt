# 더브레인코어 홈페이지 — 디자인 파일 보관함

이 폴더에 글씨체, 로고, 사진 파일을 넣어 두세요.
개발할 때 이 파일들을 홈페이지에 연결합니다.

## 폴더 안내

| 폴더 | 넣을 파일 |
|------|-----------|
| `fonts/` | 글씨체 파일 (.woff2, .woff, .ttf, .otf) |
| `logos/` | 로고 (.svg 권장, .png 가능) |
| `images/banners/` | 메인 화면·배너 이미지 |
| `images/teachers/` | 강사 프로필 사진 |
| `images/academies/` | 관·분원 사진 |
| `images/common/` | 그 외 공통 이미지 |

## 파일 이름 팁

- 공백 없이 영문·숫자 사용 (예: `tbc-logo.svg`, `hero-main.jpg`)
- 로고는 배경 없는 PNG 또는 SVG가 좋습니다.
